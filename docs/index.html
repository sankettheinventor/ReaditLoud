And none of it leaves your phone. There is no account, no server, no ads and no tracking. Your pages, your highlights and your notes stay with you.

vi.Docs

Build it yourself.

You need Node 20 and JDK 21, plus Android Studio or the Android SDK to run it on a phone. No laptop? GitHub builds the APK for you.

1Build2Run3No laptop4Release
Step 1

Build the app

git clone https://github.com/sankettheinventor/ReaditLoud
cd ReaditLoud
npm ci
PUBLIC_APP_BUILD=1 npm run build
npx cap sync android

The first build creates the app bundle in dist/; cap sync copies it into the Android project.

Step 2

Run it on your phone

npx cap open android          # opens Android Studio → press Run
# or, from the command line:
cd android && ./gradlew assembleDebug

The debug APK lands in android/app/build/outputs/apk/debug/.

Step 3

No laptop? Let GitHub build it

  • Fork the repository on GitHub.
  • Open Actions → Build APK → Run workflow, or push any change to main.
  • When it finishes, download readitloud-debug-apk from the run's artifacts and install it on your phone.
Step 4

Release build with your own key

Create android/keystore.properties next to your keystore. Both are gitignored, so they never get committed:

storeFile=release.jks
storePassword=...
keyAlias=...
keyPassword=...

Then ./gradlew bundleRelease. If you publish your own copy, change the app ID com.readitloud.app in capacitor.config.json and android/app/build.gradle.
